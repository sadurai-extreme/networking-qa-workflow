This chapter discusses the Service Probe feature, which emulates a client device
connected to your network to help you test and debug network functionality from
an end-user perspective. Using a Service Probe, you can verify DHCP configuration,
test Layer 3 connectivity via ping, validate DNS server resolution, and confirm default
gateway reachability — all from within the device itself.
This chapter provides an overview of the feature's capabilities, implementation
behavior, and example CLI commands.
