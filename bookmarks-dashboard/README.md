# 📚 Bookmarks Dashboard

A simple, self-contained HTML dashboard to manage all your bookmarks locally.

## 🚀 How to Use

1. **Open the Dashboard**: Simply double-click `index.html` or right-click and open with your browser
2. **Add Bookmarks**: Click the "+ Add Bookmark" button
3. **Edit/Delete**: Use the Edit and Delete buttons on each bookmark card
4. **Filter by Category**: Click category buttons to filter bookmarks

## ✨ Features

- ✅ Add, Edit, and Delete bookmarks
- ✅ Organize with categories and tags
- ✅ Filter bookmarks by category
- ✅ All data saved locally in your browser (localStorage)
- ✅ Clean, modern, responsive design
- ✅ No server or internet required

## 📝 Adding a Bookmark

1. Click "+ Add Bookmark"
2. Fill in the form:
   - **Title**: Name of the bookmark (required)
   - **URL**: Full web address (required)
   - **Description**: Optional notes about the bookmark
   - **Category**: Organize by category like "Development", "Design", etc. (required)
   - **Tags**: Comma-separated tags for additional organization
3. Click "Save"

## 💾 Data Storage

All bookmarks are stored in your browser's localStorage. This means:
- ✅ Data persists between sessions
- ✅ No external database needed
- ✅ Works completely offline
- ⚠️ Data is browser-specific (different browsers won't share bookmarks)
- ⚠️ Clearing browser data will delete your bookmarks

## 🎨 Categories & Tags

- **Categories**: Primary organization (e.g., "Work", "Personal", "Development")
- **Tags**: Additional labels for detailed organization (e.g., "javascript", "tutorial", "reference")
- Filter bookmarks instantly by clicking category buttons

## 📱 Responsive Design

The dashboard works great on:
- Desktop computers
- Tablets
- Mobile phones

## 🔒 Privacy

All data stays on your local machine. Nothing is sent to any server.
